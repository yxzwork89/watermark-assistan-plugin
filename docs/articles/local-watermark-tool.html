不上传服务器的图片水印工具适合哪些场景？

很多在线水印工具用起来很方便，但证件类图片包含敏感信息。对身份证、合同、营业执照这类资料，本地处理通常是更稳妥的选择。

安装 Chrome 插件隐私政策

什么是本地处理

本地处理指图片预览、文字水印渲染和导出都在用户浏览器中完成，不需要把原始图片上传到远程服务器。

适合本地处理的图片

身份证、护照、驾驶证、营业执照、户口本、合同、证书、银行开户资料和平台实名认证资料。

在线工具的风险点

如果工具需要上传原图，用户需要信任对方的存储、删除、日志和访问控制。对敏感资料来说，这个成本并不低。

Chrome 插件的优势

浏览器插件可以贴近上传流程：先水印再保存，或者在网页上传时直接插入处理后的图片。

FAQ

本地水印工具需要联网吗？

安装扩展可能需要联网，但图片水印处理本身可以在浏览器本地完成。

本地处理是否等于绝对安全？

不是。它减少了上传第三方服务器的风险，但用户仍需要保管好本机和处理后的图片。
